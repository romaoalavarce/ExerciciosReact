# ExerciciosReact
EXERCICIO REACT
1. SISTEMA DE CAIXA DE MERCADO
Um pequeno mercado precisa de uma tela rápida para o caixa
calcular compras sem usar calculadora física. O operador
digita dois valores e o sistema deve mostrar automaticamente:
soma, subtração, multiplicação, divisão
O resultado deve aparecer na tela sem recarregar a página.
Instruções:
Crie dois campos input
Adicione um botão Calcular
Converta os valores para números
Utilize useState para armazenamento7
Utilize componentes

Papel e Tesoura contra o computador.
